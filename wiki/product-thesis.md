# Product thesis

For an API or SDK company, a support agent labels a structured GitHub issue and receives a draft pull request containing one runnable Next.js/TypeScript integration recipe.

The recipe is an artifact, not a conversational answer. It contains setup instructions, an environment template, the requested operation, and a sandbox smoke command. It is reviewed before it runs with credentials.

The initial scope deliberately supports one partner, one framework, one OpenAPI source, and one sandbox host. Generalization happens only after [[pilot-plan]] establishes repeated demand.

The surrounding market is described in [[market-landscape]], while [[security-model]] defines the non-negotiable execution split.
